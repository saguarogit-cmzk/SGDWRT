    LAN adresa uređaja

    Nakon primjene uređaj mijenja adresu — bit ćeš automatski preusmjeren na novu. Na novoj adresi prijavi se ponovno istim tokenom. Prije izmjene sprema se backup konfiguracije na uređaju.

    Host

    Promjena lozinke

    Najmanje 8 znakova. Nakon promjene sve ostale sesije se odjavljuju; ova ostaje prijavljena.

    Sesije

    Odjava ostalih sesija poništava prijave u drugim browserima i na drugim računalima.

    API token

    Token za strojni pristup API-ju (skripte, integracije) — šalje se kao Authorization: Bearer <token>. Regeneriranje odmah poništava stari token; GUI prijave ostaju.
